Objective

Decide whether two equal-length strings use every letter of the alphabet at similar frequencies.

Required Operation

For each of the twenty-six lowercase letters, count how many times it occurs in word1 and how many times it occurs in word2, and take the size of the difference between those two counts. The strings qualify when every one of those differences is at most three.

Input

Two parameters, word1 and word2, both strings of lowercase English letters and both of the same length.

Output

A boolean: true when every letter's frequency difference is at most three, false as soon as any letter exceeds it.

Constraints

  • Both strings have the same length, between 1 and 100 characters.
  • Both contain only lowercase English letters.

Edge Cases

  • A letter appearing in neither string has a difference of zero.
  • A letter appearing in only one string is compared against a count of zero in the other.
  • A difference of exactly three is still acceptable.

Load Bearing

Every letter of the alphabet is checked, not only the letters that appear. The threshold is at most three, so three passes and four fails. The difference is a size and is never negative.

Method Behaviour

The method accepts both strings and returns a boolean. It does not print and does not return the differing letters.
