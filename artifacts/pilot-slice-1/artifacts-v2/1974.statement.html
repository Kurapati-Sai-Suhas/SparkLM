Given a list nums of positive integers that is not sorted and may contain repeated values, compute the greatest common divisor of exactly two numbers: the smallest value present and the largest value present.

The method must return a single integer as the output. Only the pair consisting of the minimum and the maximum participates; no other pair, not any adjacent pair, and not all elements are considered.

Constraints: the list length is between two and one thousand inclusive, each element is between one and one thousand inclusive. The list contains at least two elements.

Edge cases: if every value is the same, the smallest and largest are the same number and the output is that number. If the list contains the value one, the output is one because one divides every integer.

When the minimum and maximum are different, the result may be different from the gcd of all elements.

In a list of three numbers such as [3, 6, 4] the smallest is 3 and the largest is 6.

def findGreatestCommonDivisorOfArray(self, nums: list[int]) -> int

Example

nums = [3, 6, 4]
# smallest = 3, largest = 6, gcd = 3
output = 3
