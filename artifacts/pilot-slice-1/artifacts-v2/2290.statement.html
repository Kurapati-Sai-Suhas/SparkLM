There are n plots on each side of a street, facing each other. A plot may either contain a house or be empty. On the same side, two houses may not be placed on neighbouring plots; that is, they must not be adjacent. The restriction does not apply across the street, so a house on one side does not affect the plot opposite it. For each side, count every distinct arrangement that satisfies the rule, then combine the two sides. Because the two sides are independent, the total number of distinct arrangements for the whole street is the square of the count for one side. Return the result exactly modulo 1000000007.

Input: a single integer n (1 ≤ n ≤ 10000) representing the number of plots on each side.

Output: a single integer, the count of valid arrangements modulo 1000000007.

Edge cases: the arrangement where every plot is empty is valid and must be included. Both sides are considered, so the answer is the count for one side multiplied by the same count (i.e., squared).

Example

For n = 1:

One side can be empty or have a house → 2 possibilities.
Both sides together: 2 × 2 = 4.

Output: 4

def countNumberOfWaysToPlaceHouses(self, n: int) -> int
