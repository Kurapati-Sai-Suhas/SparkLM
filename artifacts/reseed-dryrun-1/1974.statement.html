Find Greatest Common Divisor of Array

Given an array of positive integers nums, compute the greatest common divisor (GCD) of all elements in the array.

Input: A list of integers nums where 1 ≤ length ≤ 10^5 and each element 1 ≤ nums[i] ≤ 10^9.

Output: An integer representing the GCD of all numbers in nums.

Constraints:

  • 1 ≤ len(nums) ≤ 10^5
  • 1 ≤ nums[i] ≤ 10^9

Example:

Input: [12, 15, 21]
Output: 3
Explanation: The GCD of 12, 15 and 21 is 3.

def findGreatestCommonDivisorOfArray(self, nums: list[int]) -> int
