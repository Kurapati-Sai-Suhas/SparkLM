Find Unique Binary String

You are given an array nums of n distinct binary strings, each of length n. Your task is to return any binary string of length n that does not appear in nums. It is guaranteed that at least one such string exists.

Input

  • nums: a list of n distinct strings, each consisting only of characters '0' and '1', and each having length n.

Output

A string of length n consisting of '0' and '1' that is not present in nums. If multiple answers exist, return any of them.

Constraints

  • 1 ≤ n ≤ 16
  • len(nums) == n
  • All strings in nums are distinct.

Example

Input: nums = ["01","10"]
Output: "00"
Explanation: The possible binary strings of length 2 are "00","01","10","11". The strings "01" and "10" are already used, so "00" or "11" are valid answers. The output "00" is one such answer.

def findUniqueBinaryString(self, nums: list[str]) -> str
