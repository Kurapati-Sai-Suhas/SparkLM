Objective

Given a list of positive integers, report the greatest common divisor of exactly two of them: the smallest value present and the largest value present.

Required operation

Find the minimum element and the maximum element of the list, then compute the greatest common divisor of those two numbers only. The greatest common divisor of the whole list is NOT what is wanted and is a different quantity.

Input semantics

One parameter, nums, a list of positive integers. The list is not sorted and may contain repeated values.

Output semantics

A single integer: the greatest common divisor of the smallest and largest values in nums.

Constraints

  • The list holds between 2 and 1000 integers.
  • Each value is between 1 and 1000 inclusive.

Edge cases

  • When every value is identical the smallest and largest are the same number, and the answer is that number.
  • A list containing 1 always yields 1 because 1 divides everything.

Load bearing

Exactly two values participate: the smallest and the largest. Not all elements. Not any adjacent pair. The distinction changes the answer: for [3, 6, 4] the smallest is 3 and the largest is 6, giving 3, whereas the divisor common to all three values is 1.

Method behaviour

The method accepts the list and returns one integer. It does not print, does not mutate the input, and does not return a list.

Required API

Class name: Solution

Method name: findGreatestCommonDivisorOfArray

Worked example

nums = [12, 15, 9, 30]
smallest = 9
largest = 30
gcd(9, 30) = 3
Result: 3

def findGreatestCommonDivisorOfArray(self, nums: list[int]) -> int
