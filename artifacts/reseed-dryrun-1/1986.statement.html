Find the Middle Index in Array

Given an array nums of integers, find an index i such that the sum of the elements strictly to the left of i is equal to the sum of the elements strictly to the right of i. If multiple such indices exist, return the leftmost one. If no such index exists, return -1.

Formally, find the smallest i (0 ≤ i < n) satisfying

sum(nums[0..i-1]) == sum(nums[i+1..n-1])

where sum(empty) is defined as 0.

Constraints:

  • 1 ≤ n ≤ 105
  • -104 ≤ nums[i] ≤ 104

Example:

Input: nums = [2, 3, -1, 8, 4]\nOutput: 3\nExplanation: The sum of elements left of index 3 is 2 + 3 + (-1) = 4, and the sum of elements right of index 3 is 4. Both are equal, so 3 is the middle index.

Another example:

Input: nums = [1, 2, 3]\nOutput: -1\nExplanation: No index satisfies the condition.

def findTheMiddleIndexInArray(self, nums: list[int]) -> int
