You are tasked with counting the arrangements of houses along both sides of a street. The street has n plots on each side, facing each other. Each plot may hold a house or stay empty.

There is a specific restriction: no two houses on the same side may sit on neighbouring plots. This means if a house is placed on a plot, its immediately adjacent plots on that same side must remain empty. A house on one side places no restriction on the plot opposite it.

You need to count every distinct arrangement of houses across both sides of the street. Leaving every plot empty is itself a valid arrangement and is counted. The two sides are independent; therefore, the total count of distinct arrangements across both sides is the count for one side multiplied by itself.

The input will be a single integer, n, representing the count of plots on each side of the street. The plot count n will be between 1 and 10,000, inclusive.

Your output should be a single integer: the total number of arrangements reduced modulo one thousand million and seven (1,000,000,007). You must report this exact modulo result, not the potentially larger exact count.

Implement the following method:

class Solution:
    def countNumberOfWaysToPlaceHouses(self, n: int) -> int:

Example

Input:

n = 1

Output:

4

Explanation:
For n = 1, there is one plot on each side.
Consider one side of the street:

  • Plot 1 is empty (_)
  • Plot 1 has a house (H)
There are 2 valid arrangements for one side.
Since the two sides are independent, the total distinct arrangements for both sides is the number of arrangements for one side multiplied by itself: 2 * 2 = 4.
The output is 4 reduced modulo 1,000,000,007, which is exactly 4.
