Problem Description

We are given an integer array obstacles. For each position i (0‑based) we want to know the length of the longest obstacle course that ends at i. An obstacle course is a subsequence of obstacles[0..i] that is non‑decreasing (each element is ≤ the next one) and must include obstacles[i] as its last element.

Return an array answer where answer[i] is the length of the longest valid obstacle course ending at position i.

Input

  • obstacles: a list of integers, the heights of the obstacles.

Output

  • A list of integers answer of the same length as obstacles.

Constraints

  • 1 ≤ len(obstacles) ≤ 10⁵
  • 1 ≤ obstacles[i] ≤ 10⁹

Example

Input: obstacles = [1,2,3,2]
Output: [1,2,3,3]
Explanation:
- At i = 0, the only course is [1] → length 1.
- At i = 1, we can take [1,2] → length 2.
- At i = 2, we can take [1,2,3] → length 3.
- At i = 3, a longest non‑decreasing subsequence ending at index 3 is [1,2,2] or [1,2,3,2] is not non‑decreasing, so the best length is 3.
