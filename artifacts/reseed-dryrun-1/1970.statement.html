Maximum Matrix Sum

We are given a square matrix matrix of size n × n containing integers.

In one operation you may choose any cell and multiply its value by -1. You may perform any number of operations (including zero).

After performing the operations you obtain a new matrix. Your task is to make the sum of all elements of the final matrix as large as possible and return that maximum sum.

Input

  • matrix: a list of n lists, each containing n integers, where 1 ≤ n ≤ 100 and -10⁴ ≤ matrix[i][j] ≤ 10⁴.

Output

  • An integer representing the maximum possible sum of the matrix after any sequence of sign‑flipping operations.

Constraints

  • The matrix is square.
  • All values fit in 32‑bit signed integer.

Example

matrix = [[-1, -2, -3],
          [-4, -5, -6],
          [-7, -8, -9]]

The absolute values sum to 45. There are nine negative numbers (odd), and the smallest absolute value is 1. The best we can do is 45 - 2·1 = 43.

Thus the method should return 43.

def maximumMatrixSum(self, matrix: list[list[int]]) -> int
