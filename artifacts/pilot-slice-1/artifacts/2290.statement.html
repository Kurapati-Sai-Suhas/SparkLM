Objective

Count the arrangements of houses along both sides of a street when no two houses on the same side may sit on neighbouring plots.

Operation

The street has n plots on each side, facing each other. A plot may hold a house or stay empty. Two houses on the same side may not occupy adjacent plots. A house on one side places no restriction on the plot opposite it. Count every distinct arrangement across both sides and report that count reduced modulo one thousand million and seven.

Input

One integer parameter n, the number of plots on each side of the street.

Output

A single integer, the number of arrangements reduced modulo 1000000007.

Constraints

1 ≤ n ≤ 10000.

Edge Cases

Leaving every plot empty is itself a valid arrangement and is counted. The two sides are independent, so the total is the count for one side multiplied by itself.

Details

The adjacency restriction applies only within a side, never across the street. Both sides are counted together. The result is reduced modulo 1000000007 rather than reported exactly.

Method Behaviour

The method accepts the plot count and returns one integer already reduced by the modulus. It does not print.

Example

For n = 2:

  • One side can be arranged as EE, HE or EH (E = empty, H = house), giving 3 possibilities.
  • The opposite side is independent, also 3 possibilities.
  • Total arrangements = 3 × 3 = 9.

Thus the method should return 9.

def countNumberOfWaysToPlaceHouses(self, n: int) -> int
